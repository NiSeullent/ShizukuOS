Native adaptation reduces multistop CSS gradients to supported endpoints and
reuses the Windows-7 author CSS headerbar colors where the original panel
requires an excluded bitmap. Unsupported alpha/blur/animation is disabled;
no Microsoft/Dejco imagery, logos, wallpapers, sounds, fonts or icon packages
were imported. The required Noto Sans KR font provider is kept.
