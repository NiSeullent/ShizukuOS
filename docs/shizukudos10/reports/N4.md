Tool change (`shizukudos/win64/tools/import_coverage.py`): new `--rank MD` option with `--providers`/`--ntoskrnl` writes
the full ranked table (every imported function, how many images import it, provider, whether the host exports it).
Counting was checked by hand against the per-image lists: the counts are distinct images per (provider, function);
the framework providers in the corpus (ndis, storport, scsiport, classpnp, wdfldr, wdf01000) count as images too,
so "importing images" for an ntoskrnl export is out of 23. No miscount was found; the only pitfall is scanning a tree
that holds the same `.sys` twice (e.g. `corpus/` and `packages/` together), which counts it twice — the command
above scans `corpus/` only.
