## Needed from K5 (`shizukudos/win64/dlls/`)

1. `ucrtbase.dll` should export `rand_s` (Windows' ucrtbase does; mingw-w64's UCRT import library and libstdc++'s
   `std::random_device` import it). Worked around in `webkit/compat/shzwk_compat.c` (over `ProcessPrng`).
2. `ucrtbase.dll` should export `__C_specific_handler` (Windows' ucrtbase does, as `api-ms-win-crt-private-l1-1-0`;
   mingw-w64's `crt2.o` references it). Worked around by linking the Shizuku ntdll's export first.
