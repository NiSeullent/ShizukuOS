# 설치와 첫 부팅

현재 새 설치기는 실제 설치 엔진과 연결된 네이티브 실행 파일입니다. 새 ISO의 설치·계정·재부팅 검증이 진행 중입니다. 다운로드 페이지에서 **공개된 버전의 지원 조건과 체크섬**을 먼저 확인하세요.

## 지원 조건

현재 설치 대상은 쓰기·캐시 동기화가 가능한 전체 고정 디스크이며 512바이트 섹터가 필요합니다. 원본 디스크, 사용 중인 디스크, 개별 파티션, 읽기 전용 디스크와 이동식 설치 대상은 제외합니다. 지원하지 않는 대상에는 실제 제외 사유를 표시합니다. 모든 PC·노트북에서 동작한다는 의미는 아닙니다.

## 설치 순서

1. ShizukuOS 설치 미디어로 시작하고 한국어 또는 English를 선택합니다. 현재 물리 키보드 배열은 US입니다.
2. 설치할 디스크를 직접 선택합니다. 용량·식별 정보·제외 사유를 확인합니다.
3. 최종 확인 화면에서 선택한 디스크와 변경 내용을 확인합니다. **지우고 설치**를 누르면 선택한 디스크의 모든 파티션과 파일이 삭제됩니다. GPT·EFI 부팅 영역·ShizukuFS 시스템 영역을 만듭니다.
4. 실제 파일 쓰기·다시 읽기 검증·캐시 동기화 상태를 확인합니다. 취소는 안전한 중단 지점에서 처리합니다. 일부가 기록된 상태로 중단하면 원래 내용이 자동 복구되지 않습니다.
5. 완료 검증을 통과하면 설치 미디어를 제거하고 설치된 디스크로 시작합니다.

디스크 선택과 확인 화면까지 대상 쓰기는 일어나지 않아야 합니다. 대상 식별 정보나 세대가 바뀌면 다시 선택해야 합니다. 확인 전에는 첫 디스크를 자동으로 지우지 않습니다.

## 오프라인 계정

첫 부팅은 기존 계정 권한 서비스로 로컬 계정을 등록하고 인증한 일반 사용자 세션을 시작합니다. 계정 이름은 현재 소문자 영문·숫자·밑줄·하이픈을 지원합니다. 비밀번호는 화면에서 가려지고 명령행으로 전달되지 않습니다.

계정 등록 후 중단됐다면 기존 계정으로 인증을 이어갑니다. 계정을 다시 만들지 않습니다. 프로필과 완료 기록은 실제 시스템 볼륨에 보관합니다. 다음 부팅은 기존 계정 로그인 경로를 사용합니다. 이 새 경로의 실제 설치 후 두 번 부팅 검증은 아직 진행 중입니다.

한국어 화면·문서 표시는 지원 경로가 있지만 한국어 입력기는 아직 제공하지 않습니다. 설치 중 오류가 발생하면 **자세히**에서 실제 실패 단계와 오류를 확인하세요. 설치 로그의 임시 저장 위치는 재시동 후 사라질 수 있습니다.
