# 계정·elevate·프로세스 관리

기존 계정 권한 서비스가 인증·사용자 식별·승격·샌드박스의 권한 근거입니다. UI에서 사용자 이름을 바꾸거나 환경 변수를 설정하는 것으로 권한을 얻을 수 없습니다. 첫 부팅 도우미는 커널이 실제 읽기 전용 부팅 이미지와 결속한 인스턴스만 인증 시작 권한을 받습니다.

계정 자격 증명은 소금과 PBKDF2 검증값으로 보관합니다. 보호된 계정·설정 완료 기록은 일반 사용자 파일 API로 읽거나 변경할 수 없습니다. 일반 로그인 세션은 관리자 권한 없이 시작하며 승격은 기존 `elevate`의 실제 인증 경로를 사용합니다. 완전한 보안 데스크톱·실기기 보안 인증을 뜻하지 않습니다.

## CHAINSAW / SAW

CHAINSAW는 실제 프로세스·관련 실행 상태를 검사하고 ShizukuOS의 확장 종료 경로를 호출합니다. 대기·정지·I/O 중이라는 이유만으로 좀비로 분류하지 않습니다. PID와 세대를 함께 확인하며 프로세스 트리는 자식 생성 경계와 참조 수명을 고려합니다.

```text
CHAINSAW /list /verbose
CHAINSAW /zombies /verbose
SAW <PID>
SAW <PID> /nuke
```

`SAW`는 셸 실행 대화상자에서 CHAINSAW에 연결됩니다. `/nuke`는 실제 프로세스 트리 종료입니다. 정책상 잔류 상태를 보존하는 Admissed Zombie, 안전하게 제거할 수 없는 Armored Zombie, Root Mode의 CLOSED AIR DEFENSE 보호 경계를 구분합니다.

`/charbomba`는 자동 복구에 사용하지 않습니다. 해당 PID와 현재 세대를 명시한 파괴적 실행 확인이 필요하며 실제 인증된 승격 관리자 권한을 요구합니다. 커널 패닉·자료 손실이 가능한 경로입니다. 개발 호스트에 의도적 손상을 주는 방식으로 시험하지 않습니다.

## 패닉

K64 PANIC은 실제 오류 정보를 우선 표시합니다. Dead Screen Controller와 더 낮은 NYAN fallback은 정상 커널 복구를 의미하지 않습니다. PCM·주파수 조절 비프·고정 비프·무음은 남아 있는 출력 경로를 설명합니다. 화면이 없다는 사실만으로 특정 CPU 모델의 고장을 단정하지 않습니다.

현재의 native CHAINSAW·패닉 검증 범위와 새 설치된 계정 환경의 검증 범위는 [상태 문서](status.md)에서 구분합니다.
