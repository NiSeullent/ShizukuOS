# ShizukuOS 1.0.0 — development candidate

제품 이름은 **ShizukuOS**입니다. **1.0.0은 최종 출시 목표**이며 실제 완료 기준을 충족하기 전에는 항상 development candidate 또는 개발 후보로 표시합니다. 이전 제품명과 0.1·0.9·기존 패치 버전은 보존된 소스, 바이너리, 시험 기록의 역사적 식별자입니다.

ShizukuDOS 10은 MS-DOS를 대체하여 실제 Microsoft Windows 98을 부팅하기 위한 기반입니다. Kernel32와 Kernel64도 그 기반의 구성요소입니다. 별도 커널 데스크톱과 독립 앱 실행 프로필은 구성요소 시험이며, 독립 운영체제의 완성을 프로젝트의 최종 상태로 삼지 않습니다.

## 배포

- 공식 ISO: <https://m98.nyase.kr/>에서만 배포합니다.
- GitHub: 공개 소스, 패치, 라이선스와 변경 이력을 제공합니다. ISO를 업로드하지 않습니다.
- Microsoft 설치 매체·제품 키·설치된 Windows 디스크·다른 소유자의 앱 설치기는 공개 배포에 포함하지 않습니다. 사용자 입력은 별도로 준비합니다.
- 개발 ISO의 실제 부팅 결과는 정확한 ISO 해시와 연결된 시험으로 표시합니다. 개발 구성요소 부팅을 완료된 Windows 98 설치 성공으로 바꾸어 표시하지 않습니다.

배포·미리보기 페이지는 한국어와 영어를 제공하고, 바로 다운로드와 실제 실행 화면을 중심으로 구성합니다. 화면은 원본 캡처·실행 환경·확인한 기능·남은 제한을 함께 표시합니다. 기본 페이지를 VNC 콘솔로 연결하지 않습니다.

## 실제 유저랜드의 테마 선택

고전 테마와 새 **ShizukuOS 테마** 모두 사용자가 직접 선택할 수 있어야 합니다. 웹사이트의 색상 선택만으로 이 요구를 완료했다고 판정하지 않습니다.

개발 셸 `SHZDESK.EXE`의 현재 후보 구현:

- 데스크톱의 Theme 버튼 또는 **F6**으로 선택 화면을 엽니다.
- **Classic [C]**와 **ShizukuOS [S]** 버튼으로 실제 GDI 데스크톱·파일 창·편집기 client surface 팔레트를 바꿉니다. 기본 Classic은 기존 화면 색상을 유지합니다.
- 데이터 볼륨 `D:\SHZTHEME.CFG`에 버전이 있는 정확한 18바이트 레코드로 저장합니다. 읽기는 크기·내용·종료까지 검사하고 잘못된 설정은 Classic으로 복귀합니다.
- 새 선택은 예약된 `D:\SHZTHNEW.CFG`를 `CREATE_NEW`로 만들고 완전 쓰기·flush·close·정확한 readback을 마친 다음 기존 설정 파일로 rename하여 저장합니다. 실패하면 이전 설정을 보존하며 현재 세션에만 적용됐다는 상태를 표시합니다. 다른 임시 파일을 덮어쓰지 않습니다.
- 호스트 계약 검사는 레코드 경계, 손상, 부분 읽기·쓰기, zero/oversized writes, flush·close·readback·rename 실패와 이전 설정 보존을 검사합니다. AMD64 셸 컴파일과 ASan/UBSan 검사는 실제 VM 시험을 대신하지 않습니다.

이 후보는 개발 셸이 직접 그리는 client surface를 바꿉니다. Kernel64의 창 관리자 non-client 캡션과 다른 앱, 실제 Windows 98 Explorer 전체 테마, 실제 재부팅 뒤 테마 유지 성공은 아직 별도 검증이 필요합니다.

실제 Windows 98 경로의 기존 `M98SetThemeStyle`/`M98GetThemeStyle`과 Classic/Modern 공급자는 유지합니다. 현재 `ntwddm/win98/theme_probe/probe.c`에는 C/M 키·두 버튼을 통한 프로세스 내부 선택이 있고, 핸들을 닫고 다시 열어 `WM_THEMECHANGED`와 repaint를 처리합니다. 이전 자동 전환 시험에서 Classic의 전체 화면과 Modern의 일부 팔레트는 관찰했지만 Modern 캡션·배경과 수동 선택의 실제 완료, 전역 적용·지속 설정은 아직 받아들여지지 않았습니다.

다음 실제 Windows 98 구현·시험은 별도 `theme_selector` 유저랜드 구성으로 연결합니다: 사용자 설정 저장/읽기, 각 참여 프로세스의 공급자 초기화와 테마 변경 전달, 캡션·컨트롤·메뉴의 실제 repaint, 앱 종료와 핸들 정리, 두 번의 콜드 부팅과 설정 readback, 고전 테마 복귀. 설정을 쓰거나 함수가 성공했다고 기록하는 것만으로 실제 화면 성공을 판정하지 않습니다.

## 최종 1.0.0 완료 기준

초기 계획의 필수 요구는 계속 유지합니다: ShizukuDOS를 통한 실제 Windows 98 부팅, UEFI GOP 기본 그래픽 드라이버, 요구된 가속과 드라이버, Chromium의 실제 웹 탐색, Legcord/Discord의 실제 연결·기능, 최신 오픈소스 Office의 문서 작성·편집·저장, Steam의 실제 클라이언트·네트워크·라이브러리·게임 실행. 기타 요청된 앱과 고전/ShizukuOS 테마도 실제 사용자 동작으로 시험합니다.

현재 확인된 GOP·Notepad++·VLC 및 독립 Kernel64 결과는 각 원본 기록의 범위로 보존합니다. 하나의 편집기 또는 구성요소 테마 시험 성공을 전체 최신 앱·Windows 98 기반 연결·전체 테마 완료로 합산하지 않습니다.
