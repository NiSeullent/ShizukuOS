# Retired entry-point documentation

The FAT12 writer functions and historical boot/stage2 sources remain available for explicit fixture tests. They are not active product boot inputs. See `docs/DOS10_NORMAL_BOOT.md` and the current `shizukudos/README.md` for the normal DOS10 build and remaining Windows 98 integration scope.
