## Actual source change

The retained private table embeds an aligned8192-byte NMI stack after descriptors.
SHZ_CPU_ARCH_BYTES is explicitly16384 and SHZ_CPU_ARCH_PAGES is4; compile-time
assertions enforce full fit/alignment. TSS IST3 is the actual embedded member end,
and vector2 uses IST3 with the existing non-scheduling fatal interrupt handler.
F1 retains the identical private verify handler/gate on IST1 and its TLB generation
lifetime; DF stays on IST2. No ordinary NT GS, scheduler policy, syscall, AP public
registration, allocator concurrency or user/process/wait/driver API is changed.

The pure real C builder rejects null/misaligned/overflowed resource extents and
boot/IRQ/DF overlap before writes. It permits actual host struct addresses for
host controls rather than fabricating a high canonical NMI stack. Native pre-INIT
resource admission separately checks the entire16KiB physically owned PMM span
and all prior architecture/bootstrap resource overlaps. PMM requests and pre-INIT
rollback free four pages; no post-INIT deallocation is introduced. Every page is
retained by the existing architecture lifetime, including after fatal AP entry.
Default UP allocation/entry remains off; BSP architecture behavior is unchanged.
