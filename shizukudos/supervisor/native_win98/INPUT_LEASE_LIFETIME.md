# Original input lifetime during private preparation

The ordinary builder admits each supplied original once under an actual Linux
read lease. Its exact size comes from that descriptor, and a complete bounded
SHA/EOF read must match the explicit pin and role geometry. The required five
inputs and optional WIN64 archive retain their existing CLI limits.

One ExitStack and shared SIGIO break latch hold all admitted originals while the
same descriptors supply semantic validation and private copies. Complete union
checks surround copies, source snapshots, compilation, ESP assembly and final
artifact hashing. Nested helper/result leases propagate break requests to the
outer registry. Every checkpoint also rechecks the canonical path's symlink
refusal. No caller lease token or unchecked fast mode is accepted.

Sparse stream hashing, independent copy inode/extent/hash readback and all ESP
member/full-artifact checks remain. Original sources are not reopened for the
former unleased precheck, separate semantic/copy admission or final full reread.
After the last complete live-union check, every lease unlock and FD close must
succeed before PASS publication or receipt_sink delivery. A finalization error
preserves a failed private receipt and supplies no successful sink bytes.

The tiny lifetime controls use actual leases, FDs, source copies and incompatible
writers. They explicitly model compilation, ESP creation and production capacity;
their outputs are not bootable or product evidence. Existing FAT/source compiler
checks retain their separate scopes. No NAS/media/VM performance measurement,
Windows/DOS boot, SMP, application, persistence or ISO acceptance is implied.

For `SHZ_NATIVE_INPUT_TEST_ROOT` host fixtures only, input/IO tests explicitly
model production volume capacity while preserving actual 6 GiB + 160 MiB host
memory and RAM-filesystem floors. The production 17 GiB reserve arithmetic is
still invoked; ordinary CLI behavior has no capacity override. The suite bounds
actual fixture allocation, and keeps logical sparse extents separately scoped.
The two real FAT fixtures reuse ActualSparseAssembly's explicit test bootstrap
prepend to model the worker's stdlib free-capacity observation. The unchanged
held packer bytes still compile with their ordinary namespace and actual main. SHA/lease/IPC/FAT/complete member checks and production 17 GiB constants are
unchanged. This cross-process capacity model is confined to the test harness.
