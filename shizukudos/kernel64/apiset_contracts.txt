# API-set contract table of the Kernel64 PE32+ loader: the source of kernel64/apiset_table.h.
# Regenerate with:  python3 shizukudos/win64/tools/gen_apiset_table.py      (--check verifies the header is current)
#
# Row:  <contract-lL-M-m>  <windows host>  [<shizuku host>]   [# note]
#
#   contract-lL-M-m  the contract name with its level (lL) and highest version (major M, minor m) this row provides.
#                    An import of the same contract and level resolves through the row with the highest version,
#                    provided that version is >= the requested one (versions of one level are cumulative):
#                    l1-1-0 and l1-2-0 are both satisfied by an l1-2-1 row; l1-3-0 is not; l2-1-0 is another contract.
#   windows host     the DLL hosting the contract in the Windows 10/11 x64 API-set schema. Every row whose contract
#                    and level also appear in Wine 9.0's apisetschema.dll (dlls/apisetschema, LGPL; only the facts are
#                    used, no code) carries the same host as Wine records; win64/tests/test_apiset.py verifies that.
#                    Rows Wine does not list carry a `# src:` note naming the public source.
#                    Background: learn.microsoft.com "Windows API sets" and "API set loader operation".
#   shizuku host     the Shizuku DLL that implements the contract, when it differs from the Windows host (for example
#                    Shizuku has no kernelbase.dll: its functions live in kernel32.dll). Defaults to the windows host,
#                    after the @provider substitutions below.
#
# Resolution only succeeds when the Shizuku host exists and (for load-time imports) exports the imported name;
# otherwise the import fails and the loader's diagnostic names the contract, the host and the function. A host that
# Shizuku does not ship (ucrtbase.dll, user32.dll, shcore.dll, ...) makes the contract fail exactly like a missing DLL.
