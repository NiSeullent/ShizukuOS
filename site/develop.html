ShizukuOS 자체의 기반.

ShizukuOS는 운영체제 자체입니다. ShizukuOS Core와 기존 한국어 실행형 셸을 확장하고, 테마·사운드·드라이버·앱·Linux Subsystem·가상화를 연결하는 독립 OS를 개발합니다. 아래 기능은 실제 구현과 실행 검증을 기다리는 목표입니다.

GitHub 소스개발 환경

ShizukuOS에서 시작하는 구조

최상위 플랫폼은 ShizukuOS입니다. ShizukuOS Core 아래에 ShizukuDOS, Kernel Layer와 Driver Layer를 두고 ShizukuVM, Linux Subsystem, Native Runtime을 연결합니다. 아래는 구현·통합·실제 검증이 필요한 목표 구조입니다.

ShizukuDOS

DOS Mode, Protected Mode, Long Mode와 v8086 실행 환경을 제공합니다. 기존 구현을 조사하고 확장하며 중복 구성요소를 만들지 않습니다.

Kernel Layer

Kernel32·Kernel64, SHZLB.sys와 VM Services를 연결하는 계층입니다. 자원·권한·수명은 ShizukuOS의 서비스 계약에 따라 관리하는 것이 목표입니다.

Driver Layer

Native·Legacy·Wrapped 드라이버를 계층으로 연결합니다. ACPI, PCI/PCIe, USB, 저장장치, 네트워크, 오디오와 디스플레이 등 표준 하드웨어를 우선합니다.

Native Runtime

ShizukuOS 실행 파일로 빌드·패키징·실행하는 자체 셸과 앱의 기반입니다. Windows 10 x86/x64 API 호환은 실제 동작을 검증해야 할 목표입니다.

실행형 셸과 데이터 기반 테마

기존 네이티브 셸과 라이선스가 호환되는 구성요소를 재사용·확장합니다. 기본 테마 목표는 Slade이며, 정돈된 Flute와 실험적인 Jade를 함께 준비합니다. 창·글꼴·아이콘·버튼·메뉴·효과·애니메이션·배경·커서·사운드를 테마 정의 데이터로 바꾸는 것이 목표입니다.

시작·종료·로그인·알림·오류·장치 연결 등의 시스템 사운드는 필수입니다. 구현 시 기존에 사용 가능한 사운드 소스를 먼저 확인해야 합니다. 테마와 사운드는 아직 전체 실제 실행 검증을 마치지 않았습니다.

ShizukuVM과 Linux Subsystem

ShizukuVM은 ShizukuOS의 고유 VM API와 커널 가상화 서비스입니다. Linux Subsystem은 SHZLB.sys를 통해 Linux 커널 샌드박스와 POSIX 실행 환경을 연결하는 Core 구성요소입니다. 초기 chkrnl /mode linux와 chkrnl /mode msdos는 커널이 지원해야 할 실행 환경입니다.

ShizukuLB — Shizuku Linux Basebuild는 Nix를 패키지 기반으로 사용하고 pkgs 명령을 Nix 환경과 동기화합니다. Linux 앱의 X 세션은 SHZLB.sys와 Shizuku Window Bridge를 거쳐 일반 데스크톱 창으로 연결하는 것이 목표입니다. 이 전체 경로의 완료는 아직 검증되지 않았습니다.

기본 네이티브 앱 목표

Terrasphere

WebKit 기반의 가벼운 네이티브 브라우저. 실제 페이지 탐색과 현대적인 사용자 경험을 목표로 합니다.

Muzik

메타데이터·재생 목록·시각화를 갖춘 음악·영상 라이브러리 앱.

Sapphire

가벼운 사진 보기와 필요할 때 불러오는 이미지 편집·그리기 기능.

Folio

기존 오픈소스 문서 처리 구현을 재사용하고 ShizukuOS의 디자인과 연결합니다.

각 앱의 사용 가능한 실행 경로와 실제 기능 검증이 필요합니다. 이름이나 UI만으로 완성된 앱으로 표시하지 않습니다.

1.0.0의 완료 기준

안정적인 부팅부터 드라이버·셸·사용자 정의 테마·사운드·네트워크·파일시스템·앱·브라우저·미디어·그래픽·Linux Subsystem·가상화·게임까지 실제 ShizukuOS 환경에서 검증해야 합니다. 자체 설치 시스템, 두 번의 콜드 부팅과 보안·정상 종료도 확인합니다. 커널 부팅이나 과거 캡처만으로 완료 판정하지 않으며 최종 수락은 미완료입니다.
