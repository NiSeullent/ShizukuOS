개발·소스

Windows 98에 새 기반을.

Windows 98의 모습과 코드를 이어, ShizukuCore와 32·64비트 Win32 계층을 결합하는 혼합 OS를 개발합니다.

GitHub 소스개발 환경

ShizukuCore와 하위 계층

최상위 ShizukuCore Kernel 아래에 네 계층을 통합하는 것이 목표입니다. 현재 부팅·호환 경로를 유지하면서 공통 자원과 권한을 서비스별로 이전합니다. 공통 코어의 통합 완료를 뜻하지 않습니다.

ShizukuDOS (SZRm)

ShizukuCore 아래의 DOS 호환·부팅·복구 계층입니다. 현재 DOS16은 고정 FreeDOS·FreeCOM과 기록된 패치를 출발점으로 사용합니다.

ShizukuOS (Windows 98)

Windows 98의 코드·사용자 영역·사용 방식을 이어갑니다. 기존 VMM·USER·GDI·Explorer 경로에서 시작해, 실제 창·입력·파일·앱 동작을 보존하며 점진적으로 전환합니다.

Shizuku32 (SZPrtm)

기존 Kernel32를 출발점으로 32비트 실행·서비스를 발전시키고 Shizuku Win32 x86 호환 계층을 연결합니다.

Shizuku64 (SZLm)

기존 Kernel64와 x64 런타임에서 실제 64비트 앱의 API·창·입력·파일 서비스를 연결합니다. 단독 구성요소 시험은 통합 검증과 구분합니다.

그래픽·드라이버·호환 계층

GOP 출력, 저장장치·USB·PCI-E, NT 앱 API를 연결합니다. 기본 GOP 출력은 GPU 3D 가속 완료가 아닙니다.

1.0.0의 완료 기준

선언한 전환 단계에서 Windows 98 사용자 영역과 ShizukuCore 서비스의 실제 부팅·왕복, 두 번의 콜드 부팅, 드라이버·가속·앱 기능·정상 종료, 자체 설치 시스템을 실제 실행으로 검증해야 합니다. 현재 최종 수락은 미완료입니다.
