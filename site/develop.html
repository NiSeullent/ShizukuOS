ShizukuOS의 본체는 실제 Windows 98입니다. ShizukuDOS가 MS-DOS 기반을 대체하고, 보호 모드·64비트 서비스와 현대 하드웨어를 Windows 98에 연결하는 것이 목표입니다.

GitHub 공개 소스다른 환경에서 개발 이어가기

통합 아키텍처

Windows 98이 시스템의 중심입니다.

Windows 98 환경

VMM · USER · GDI · Explorer

실제 Windows 98의 VMM, Win16/Win32 앱 환경과 데스크톱을 유지합니다. 창·입력·파일·앱 수명이 이 환경에서 이어져야 합니다.

DOS → VMM 연결 개발 중

ShizukuDOS

Windows 98이 사용하는 MS-DOS 기반을 대체합니다. 현재 DOS16은 고정 FreeDOS·FreeCOM 소스와 기록된 패치에 기반한 호환 부트스트랩입니다. WIN.COM 시작과 DOS 상주 상태·초기화 계약의 실제 연결을 구현하고 있습니다.

서비스 구성요소

Kernel32 · Kernel64 · PMA

Kernel32는 보호 모드 서비스, Kernel64는 Long Mode와 x64 라이브러리 실행을 맡습니다. PMA와 Supervisor는 Windows 98의 실행 상태를 보존하며 서비스 요청을 연결하기 위한 기반입니다. 단독 커널 부팅과 내부 loopback은 구성요소 시험입니다.

전체 통합 검증 필요

GOP · 드라이버 · NT 호환 계층

UEFI GOP의 기본 화면 출력, 현대 저장장치·USB·PCI-E와 NT 계열 앱 API를 Windows 98에 연결합니다. GOP 소프트웨어 출력은 GPU 3D 가속 완료를 뜻하지 않으며, API 이름이나 빌드 성공만으로 앱 기능을 지원한 것으로 판정하지 않습니다.

검증 단계확인하는 내용전체 완료를 위해 남은 내용
소스·호스트 검사실제 소스의 ABI, 경계·수명·오류 처리, 입력 해시와 빌드 결과를 검사합니다. 특권 CPU·장치 경계를 모델링한 시험은 그 범위를 표시합니다.호스트 검사와 컴파일 성공은 Windows 98 게스트 부팅이나 앱 실행의 증거가 아닙니다.
독립 구성요소 실행실제 CPU·UEFI·커널·서비스·디스크의 제한된 동작을 시험합니다. 독립 Kernel64 앱 기록도 이 단계로 분류합니다.Windows 98의 VMM·창·입력·파일 수명과 연결한 시험이 필요합니다.
원래 DOS 경로의 Win98 대조 시험실제 Windows 98의 GOP 출력과 제한된 Notepad++·VLC 작업을 원본 캡처로 보존합니다.Microsoft DOS를 실행한 대조군은 ShizukuDOS가 MS-DOS를 교체했다는 증거가 아닙니다.
ShizukuDOS 기반 Windows 98최종 수락 미완료

ShizukuDOS 진입 → WIN.COM → 실제 VMM과 Windows 98 데스크톱, Windows ↔ PMA 서비스 왕복을 실제 실행으로 확인해야 합니다.

두 번의 콜드 부팅, GOP·입력·저장·재열기, 필수 드라이버와 가속, 각 앱의 실제 기능·정상 종료가 필요합니다.
1.0.0 설치·배포최종 배포 준비 중

프로젝트 자체 설치 시스템, Classic·ShizukuOS 테마, 최종 ISO와 체크섬을 같은 검증된 소스로 준비합니다.

실제 설치·재부팅·전체 통합 검증과 공식 다운로드의 전달 확인이 필요합니다. 현재 개발 ZIP과 구성요소 ISO로 대체하지 않습니다.

원본 성공·실패 기록은 보존합니다. 공개 화면은 13개 실제 시험 모음에서 환경과 미검증 범위를 함께 확인할 수 있습니다.

개발 시작점

소스와 재현 자료를 함께 읽으세요.

공개 소스

GitHub에는 공개 가능한 개발 소스와 패치를 제공합니다. 프로젝트 README에서 현재 경로와 과거 경로를 확인하세요.

소스 저장소 열기

빌드·개발 환경

Linux 빌드 도구와 단계별 명령, 실제 입력 준비와 현재 한계는 인계 문서에 있습니다. 전체 ISO에는 DOS16·UEFI·Win64 도구가 추가로 필요합니다.

개발 환경 안내

앱 재시험

원본 앱의 버전·공식 체크섬·전체 파일 해시를 고정하고, 실제 앱 기능을 각각 시험합니다. 공통 API 통과와 최종 앱 수락을 분리합니다.

앱별 다음 작업

공식 배포

최종 ShizukuOS 1.0.0은 자체 설치 시스템을 사용합니다. ISO는 m98.nyase.kr에서만 배포하며 GitHub는 공개 개발 소스·패치의 배포 경로입니다.

현재 다운로드 범위

Windows와 앱 원본은 사용자가 준비합니다.

Microsoft 설치 미디어·제품 키·설치된 개인 디스크·비공개 VM·비밀정보를 공개 소스나 다운로드에 포함하지 않습니다. 실제 Windows 98와 앱의 원본 입력은 사용 권한이 있는 자신의 자료로 준비합니다.
