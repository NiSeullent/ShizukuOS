실행 환경을 함께 확인하세요.

Notepad++와 VLC의 제한된 시험은 실제 Windows 98에서 기록했습니다. 이 기록은 기존 DOS 부팅 경로의 대조 시험이며, ShizukuDOS로 MS-DOS를 교체한 Windows 98 부팅을 입증하지 않습니다.

독립 Kernel64 실행기, API 시험, Linux·XP 등의 다른 환경에서 얻은 결과도 Windows 98의 앱 지원 완료로 계산하지 않습니다. ShizukuDOS 기반의 Windows 98 통합과 전체 앱 기능은 아직 검증 중입니다.
