이 안내는 현재 배포하는 개발 ZIP의 필수 조건을 설명합니다. 최종 자체 설치 ISO의 안내는 실제 설치 검증 후 별도로 제공합니다.

최종 설치·부팅 미완료

시험용 Windows 98 SE 설치본부터.

현재 수동 구성은 기존 Windows 98 설치본을 사용합니다. 원래 Microsoft DOS로 부팅한 시험을 ShizukuDOS 기반 통합 부팅으로 표시하지 않습니다. 설치 미디어와 앱 원본은 직접 준비하고 기존 설치본과 설정을 백업하세요.

먼저 확인할 조건

Notepad++ 8.9.8.1

  • 한국어 OEM Windows 98 SE 시험 환경. 다른 에디션과 새 설치본의 ZIP 단독 설정은 미검증입니다.
  • KernelEx 4.5.2·Microsoft Unicode Layer·공식 x86 portable 편집기 원본이 별도로 필요합니다.
  • ZIP의 전용 NTWPENV 실행기를 사용합니다. 일반 실행의 종료 오류가 있었으며, 임의의 새 앱 버전에는 적용하지 않습니다.
정확한 수동 단계·앱 해시·소스 안내

GOP 기본 그래픽 드라이버

대응 Shizuku CSMWrap 펌웨어 GOP 부팅 경로와 보존된 SHZLOC1/SHZGOP1 정보가 필요합니다. ZIP만 복사한다고 일반 펌웨어에 그 경로가 생기지는 않습니다.

검증 범위는 고정 해상도의 32비트 BGRX 출력과 Windows DIBEngine 기반 그리기입니다. 동적 해상도·DOS 전체 화면 전환·GPU 3D 가속은 별도 작업입니다.

실제 설치·출력 기록

수동 미리보기의 진행 순서

  1. 파일과 SHA-256 확인

    다운로드 페이지에서 크기·체크섬을 확인하고 ZIP의 해당 소스·라이선스·README를 읽습니다.

  2. 시험 설치본과 필수 조건 준비

    기존 KernelEx 디렉터리·CORE.INI·레지스트리를 백업합니다. 원본 편집기의 정확한 파일 해시와 기존 설정을 확인합니다.

  3. 해당 README의 좁은 설정만 적용

    호환 DLL·FileSaveDialog·앱별 KernelEx 경로와 전용 실행기를 설정합니다. 전체 기본 프로필이나 다른 앱에 일괄 적용하지 않습니다. 앱 원본은 변경하지 않습니다.

  4. 콜드 부팅 후 실제 동작 확인

    먼저 20개 진단 fixture 조건과 실제 자식 종료 0을 확인합니다. 편집기의 편집·Save As·파일 내용·다시 열기·정상 종료를 확인합니다. 시험의 제한 시간과 실패는 그대로 기록합니다.

Notepad++의 Save As 단축키는 Ctrl+Alt+S입니다. 전체 Windows 종료와 다른 앱의 정상 동작은 별도로 검증해야 합니다.

도구 소스 · 호스트 fixture 9개

USB 도구와 사용자 소유 미디어

USB helper ZIP은 사용자 소유 설치 미디어를 로컬에서 조합하기 위한 소스·문서입니다. 공개 전체 USB payload, 실제 USB 부팅과 Windows Setup 부팅은 아직 검증되지 않았습니다. 개인 미디어·설치된 디스크·제품 키는 업로드하거나 공개하지 않습니다.
