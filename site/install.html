Pre-Beta 01 · 준비 중

시험 환경부터 준비하세요.

지금 배포하는 구성요소 ZIP의 수동 설치 안내입니다. Pre-Beta 01 설치 ISO는 검증을 기다리고 있습니다.

시험용 Windows 98 SE 설치본이 필요합니다.

기존 설치본과 설정을 백업하고 Windows·앱 원본은 직접 준비하세요. 기존 공개 시험은 원래 Microsoft DOS/VMM 부팅 경로를 사용하며, 새 ShizukuCore 통합 부팅을 입증하지 않습니다.

Pre-Beta 01 공개 전 확인할 것

첫 검증 대상은 x86_64 UEFI 가상 머신입니다. 아래 네 조건은 모두 검증 대기 중입니다. 배포 시 실제 전환 단계와 남아 있는 DOS/VMM 의존성을 표시합니다.

검증 대기

Windows 98 부팅

실제 Windows 98의 창·입력·파일 작업과 ShizukuCore 서비스 연결을 확인합니다.

검증 대기

UEFI 대상 디스크 설치

프로젝트 설치 프로그램으로 시험용 대상 디스크에 설치합니다.

검증 대기

ISO 없이 콜드 부팅

설치 ISO를 제거한 뒤 설치 디스크에서 다시 부팅합니다.

검증 대기

설치된 GOP 기본 그래픽 및 코어 드라이버

설치된 GOP 드라이버의 실제 화면 출력을 확인하고 설치된 코어 드라이버를 식별합니다.

Windows 98 설치 미디어는 사용자가 소유한 파일을 로컬에서 준비합니다. Windows 설치 파일·제품 키·개인 설치 디스크는 공개 배포하지 않습니다.

Pre-Beta 01에서 현대 앱의 실제 기능은 미검증입니다. 기존 앱별 시험 상태를 확인하세요. 최종 1.0.0의 전체 개발 목표는 유지합니다.

필수 조건

Notepad++ 8.9.8.1

  • 한국어 OEM Windows 98 SE 시험 환경.
  • KernelEx 4.5.2, Microsoft Unicode Layer, 공식 x86 portable 앱 원본.
  • ZIP의 전용 NTWPENV 실행기. 일반 실행에는 종료 오류가 있었습니다.

다른 에디션·새 설치본·다른 앱 버전은 미검증입니다.

설정 단계와 원본 앱 해시

GOP 그래픽 드라이버

Shizuku CSMWrap GOP 부팅 경로와 SHZLOC1/SHZGOP1 정보가 필요합니다.

현재 범위는 고정 해상도 32비트 BGRX·DIBEngine 그리기입니다. 동적 해상도·DOS 전체 화면·GPU 3D 가속은 미완료입니다.

설치·출력 기록

설치 순서

  1. 파일 확인

    다운로드 페이지의 크기·SHA-256을 확인하고 ZIP의 README를 읽습니다.

  2. 설정 백업

    KernelEx 디렉터리, CORE.INI, 레지스트리를 백업합니다. 앱 원본 해시를 확인합니다.

  3. README대로 적용

    앱별 호환 DLL·FileSaveDialog·KernelEx 설정과 전용 실행기를 적용합니다. 앱 원본은 수정하지 않습니다.

  4. 콜드 부팅 후 확인

    20개 진단 fixture와 자식 종료 0을 확인합니다. 편집·Save As(Ctrl+Alt+S)·다시 열기·정상 종료를 시험합니다.

전체 Windows 종료와 다른 앱은 별도 검증 대상입니다.

USB 도구는 소스 미리보기입니다.

사용자 소유 미디어를 로컬에서 조합합니다. 호스트 fixture 9개는 통과했으나 실제 USB·Windows Setup 부팅은 미검증입니다. 개인 미디어·제품 키·설치 디스크는 공개하지 않습니다.
