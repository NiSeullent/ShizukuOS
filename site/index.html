02 / SETUP GUIDE

독립 계층 시험 방법

개발용 소스를 빌드하고 원본을 보존한 시험 환경에서 검증합니다. 새 경로의 Windows 98 실행은 아직 미검증입니다.

01

시험 환경 준비

사용 권한이 있는 Windows 98 SE 설치 미디어로 시험 VM을 만듭니다. 이 프로젝트가 확인한 VirtualBox 환경은 BIOS/IDE, CPU 1개, RAM 128 MiB였습니다. 다른 하드웨어 구성의 동작은 별도 검증이 필요합니다.

별도 준비
02

독립된 시험 복제본

KernelEx가 없는 Windows 98 SE 설치본을 보존하고, 네트워크가 없는 별도 복제본을 사용합니다. 실제 시스템 설치와 시험 결과를 구분해 기록합니다.

게스트
03

독립 DLL 빌드

Python, GCC/Clang, 32비트 MinGW가 있는 Linux 개발 환경에서 실행합니다. 결과물은 build/platform/NTW32.DLL과 시험 프로그램입니다.

Build_ □ ×
python3 platform/build.py

호스트
04

앱 사본 준비

ntwin32/prepare.py로 지원 API만 NTW32.DLL에 연결한 앱 사본을 만듭니다. 원본은 보존하며, 지원 범위를 벗어난 실행 파일은 중단합니다. DLL은 시험 앱 옆에 둡니다.

게스트
05

동작 확인

NTWPROBE.EXE의 종료 코드와 NTWPROBE.LOG를 확인합니다. 현재 새 경로는 호스트 구조·동시성 시험을 통과했으며 Windows 98 실행 결과는 아직 없습니다. UEFI와 드라이버 시험은 별도로 기록합니다.

시험

ShizukuDOS

개발 중 / IN PROGRESSPCI-E foundation

하드웨어와 앱 호환성

장치·브리지 탐색, ECAM과 자원 범위 검사를 구현했습니다. 실제 AHCI/xHCI/NVMe 드라이버, GPU 가속과 필수 앱의 기능 검증은 아직 남아 있습니다.

ⓘ
