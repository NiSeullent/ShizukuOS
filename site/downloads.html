첫 검증 대상은 x86_64 UEFI 가상 머신입니다. 아래 네 조건은 모두 검증 대기 중입니다. 배포 시 실제 전환 단계와 남아 있는 DOS/VMM 의존성을 표시합니다.

검증 대기

설치된 GOP 기본 그래픽 및 코어 드라이버

설치된 GOP 드라이버의 실제 화면 출력을 확인하고 설치된 코어 드라이버를 식별합니다.

Windows 98 설치 미디어는 사용자가 소유한 파일을 로컬에서 준비합니다. Windows 설치 파일·제품 키·개인 설치 디스크는 공개 배포하지 않습니다.

Pre-Beta 01에서 현대 앱의 실제 기능은 미검증입니다. 기존 앱별 시험 상태를 확인하세요. 최종 1.0.0의 전체 개발 목표는 유지합니다.
