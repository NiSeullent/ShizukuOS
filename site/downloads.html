ShizukuOS 통합 설치 ISO

독립 OS ShizukuOS의 자체 설치판은 아직 공개하지 않았습니다. 아래 ZIP은 개발 구성요소이며, Windows 설치 파일·제품 키·앱 원본은 포함하지 않습니다.

설치 조건 확인
Pre-Beta 01 · 준비 중

설치 ISO는 검증 대기 중입니다.

자체 설치·부팅·드라이버를 검증한 뒤 실제 ISO 파일의 크기와 SHA-256을 함께 게시합니다. 현재 Pre-Beta 01 ISO 다운로드는 없습니다.

OS 설치판과 구성요소 ZIP은 용도가 다릅니다.

ShizukuOS 설치판은 자체 설치·부팅·드라이버와 데스크톱의 실제 검증을 마친 뒤 공개합니다. 지금 제공하는 ZIP은 과거 Windows 98 호환 환경용 개발 구성요소입니다.
