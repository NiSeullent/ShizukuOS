현재 확인된 동작

실제 Windows 98에서 Notepad++ 편집·저장·다시 열기와 UEFI GOP 화면 출력을 확인했습니다. VLC는 메뉴와 움직이는 영상을 표시했으며 종료 오류가 남아 있습니다. 독립 64비트 실행기에서는 Chromium의 DOM 계산 결과와 Legcord 설정 화면을 확인했습니다. Chromium 그래픽 시험은 도구 모음까지 표시한 뒤 페이지 로딩과 종료 오류가 남았습니다.

NEXT / 남은 구현

공통 호환 기능부터 연결합니다.

Chrome·Chromium·Firefox·Discord·Steam·최신 Office를 위한 공통 커널, 파일·문자열·프로세스 기능과 화면·입력을 확장하고 있습니다. 실제 UEFI/VMX/EPT 기반 64비트 실행기 기초 시험 37개는 통과했지만, 설치된 Windows 98과 현대 앱을 연결하는 전체 경로는 아직 검증되지 않았습니다.

공통 런타임 V44의 일반 빌드와 실제 독립 게스트 API 시험 252개를 통과했습니다. 모듈 열거·검색 경로·토큰·UCRT·파일 복사·RTL 기능을 확인한 결과이며, 현대 앱의 기능 시험과 설치된 Windows 98 연결은 별도로 남아 있습니다. 앞선 V43 빌드 실패 기록도 보존했습니다.

SETUP / 준비 범위

본인 환경에서 준비할 것

인계 문서의 도구 버전과 빌드 경로를 확인하고, 앱 원본은 각 공식 배포처에서 다시 받아 해시를 비교하세요. 실제 게스트 시험에는 적법하게 보유한 Windows 98 설치본과 가상화 환경이 필요합니다.

이 웹 페이지와 소스 저장소는 Windows 설치 미디어, 제품 키, 앱 원본 설치 패키지, 가상머신 디스크를 배포하지 않습니다. 화면은 실제 기록이며 웹에서 Windows 98이 실행되는 실시간 콘솔이 아닙니다.
