# Windows 98 Shizuku's Second Edition — site source

Open `index.html` in a browser, or serve this directory with `python -m http.server 8080` and open `http://localhost:8080/`.

As reviewed on 2026-09-27, the page introduces the independent platform, its
source-build instructions and current limitations. The download and checksum
links still identify the historical `v0.1.1-preview` KernelEx release, which the
page labels separately; those asset URLs are preserved. Current build and
validation details are in the [independent platform guide](../platform/README.md).
This directory contains site source and does not establish a deployment or a
completed Windows 98 distribution.
