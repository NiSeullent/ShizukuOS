One app, one actual record

How far does each app run?

From editing and saving to browsers and office tools. Each app has its own verified behavior and remaining work.

These public records were frozen on October 1, 2026. Versions identify the inputs to those trials; they are not a claim about the latest release today.

Actual Notepad++ capturesActual VLC captures

Check the execution environment too.

The limited Notepad++ and VLC trials were recorded in actual Windows 98. They used the original DOS boot path as a control; they do not establish Windows 98 booting after ShizukuDOS replaces MS-DOS.

Independent Kernel64 runs, API fixtures and results from other environments such as Linux or XP also do not establish completed Windows 98 application support. Windows 98 integration on ShizukuDOS and complete application functionality remain under verification.
