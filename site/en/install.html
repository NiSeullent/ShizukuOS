Prerequisites

Notepad++ 8.9.8.1

  • The accepted trial used Korean OEM Windows 98 SE. Other editions and fresh-machine ZIP-only setup remain unverified.
  • KernelEx 4.5.2, Microsoft Unicode Layer and the official x86 portable editor are separate prerequisites.
  • Use the included NTWPENV launcher. Earlier unassisted exit failed; the launcher does not accept arbitrary later app versions.

GOP basic graphics driver

Requires the matching Shizuku CSMWrap firmware GOP boot path and retained SHZLOC1/SHZGOP1 information. Copying this ZIP does not add that boot path to ordinary firmware.

Acceptance covers a fixed 32-bit BGRX mode and Windows DIBEngine drawing. Dynamic resolution, fullscreen DOS switching and GPU 3D acceleration require separate implementation.

Manual preview sequence

  1. Verify the file and SHA-256

    Check sizes and checksums on the download page. Read the corresponding source, licenses and README inside the ZIP.

  2. Prepare the test installation

    Back up the KernelEx directory, CORE.INI and registry. Check the exact original editor hash and existing settings.

  3. Apply only the documented scoped settings

    Configure the compatibility DLLs, FileSaveDialog, exact app KernelEx path and dedicated launcher. Preserve unrelated profiles and apps. The application original remains unchanged.

  4. Cold boot and check actual behavior

    First require all 20 diagnostic fixture controls and actual child exit zero. Check editing, Save As, exact saved bytes, reopen and clean app exit. Preserve time limits and actual failures.

Notepad++ uses Ctrl+Alt+S for Save As. Whole-system shutdown and other applications require separate acceptance.
