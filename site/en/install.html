Installation steps

  1. Verify the files

    Check the download size and SHA-256, then read the bundled README.

  2. Back up settings

    Back up the KernelEx directory, CORE.INI and registry. Verify the original app hash.

  3. Follow the package README

    Apply app-specific compatibility DLLs, FileSaveDialog and KernelEx settings. Use the dedicated launcher; keep original app files intact.

  4. Check after a cold boot

    Verify 20 diagnostic fixtures and child exit 0. Test editing, Save As (Ctrl+Alt+S), reopening and normal exit.

Full Windows shutdown and other applications require separate verification.

The USB helper is a source preview.

It prepares user-owned media locally. Nine host fixtures passed; actual USB and Windows Setup boot remain unverified. Keep personal media, product keys and installed disks private.
