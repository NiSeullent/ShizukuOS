Windows 98, on a new foundation

Connecting the familiar
system all the way through.

Actual Windows 98 is the core of ShizukuOS. The goal is to replace its MS-DOS foundation with ShizukuDOS and connect protected-mode services, 64-bit execution and modern hardware to Windows 98.

Public source on GitHubContinue development elsewhere

Integration architecture

Windows 98 remains at the center.

Windows 98 environment

VMM · USER · GDI · Explorer

The actual Windows 98 VMM, Win16/Win32 application environment and desktop are preserved. Window, input, file and application lifetimes must remain connected to this environment.

DOS → VMM connection in development

ShizukuDOS

Replaces the MS-DOS foundation used by Windows 98. Current DOS16 uses a compatibility bootstrap based on pinned FreeDOS and FreeCOM sources with recorded patches. Actual WIN.COM startup and DOS resident-state and initialization contracts are being implemented.

Service components

Kernel32 · Kernel64 · PMA

Kernel32 supplies protected-mode services; Kernel64 supplies Long Mode and x64 library execution. PMA and the Supervisor provide the foundation for connecting service requests while preserving Windows 98 execution state. Standalone kernel boots and internal loopback are component tests.

Full integration verification required

GOP · drivers · NT compatibility

Connects basic UEFI GOP display output, modern storage, USB, PCI-E and NT application APIs to Windows 98. GOP software output does not establish GPU 3D acceleration. API names or a successful build do not establish application functionality.
