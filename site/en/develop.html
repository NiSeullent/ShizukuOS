Development and source

A new foundation for Windows 98.

Run actual Windows 98 on ShizukuDOS and connect modern hardware and applications.

GitHub sourceBuild environment (Korean)

System components

ShizukuDOS

Replaces the MS-DOS foundation. Current DOS16 uses pinned FreeDOS and FreeCOM with recorded patches. WIN.COM → VMM integration is in development.

Actual Windows 98

Retains VMM, USER, GDI and Explorer. Windows, input, files and application execution must remain connected inside Windows 98.

Kernel32 · Kernel64 · PMA

Components for protected-mode and x64 services with the Supervisor. Standalone kernels and loopback tests are separate from integration verification.

Graphics, drivers and compatibility

Connects GOP output, storage, USB, PCI-E and NT application APIs. Basic GOP output does not establish GPU 3D acceleration.

Acceptance criteria for 1.0.0

Actual execution must verify ShizukuDOS → WIN.COM → Windows 98 boot, service round trips, two cold boots, drivers, acceleration, app functionality, clean exits and the project installer. Final acceptance remains incomplete.
