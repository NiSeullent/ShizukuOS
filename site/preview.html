실제로 돌아가는 모습.

부팅부터 편집·저장까지, 실제 시험에서 기록했습니다.

기록된 실제 Windows 98 시험은 기존 DOS 부팅 경로의 대조군입니다. ShizukuDOS 기반 통합 부팅은 아직 미완료입니다. 독립 실행기의 화면은 각 모음에서 구성요소 시험으로 표시합니다.

원본 실행 기록입니다. 전체 화면 선택과 타임라인은 JavaScript를 사용합니다.

부팅·가속과 앱 지원 범위

실제 Windows 98의 UEFI GOP 부팅과 기본 그래픽 출력을 확인했습니다. 최신 Notepad++는 전용 실행기로 편집·저장·다시 열기·정상 종료를 확인했습니다.

다른 최신 앱, 전체 드라이버와 GPU 3D 가속은 개발 중입니다. ShizukuDOS 10과 Kernel32·Kernel64는 Windows 98을 위한 구성요소이며, 독립 실행 기록은 구성요소 시험으로 표시합니다.
