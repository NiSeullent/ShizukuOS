ShizukuOS 문서

ShizukuOS는 자체 커널 계층, 네이티브 실행 환경과 실행 파일 기반 데스크톱을 갖추는 독립 운영체제입니다. 현재 Pre-Beta 01을 통합·검증하고 있습니다.

  • 설치와 첫 부팅
  • 데스크톱·설정·파일 작업
  • 계정·elevate·프로세스 관리
  • 개발·빌드
  • 구현 상태와 검증 범위
  • 커널 인터페이스
  • 공식 다운로드

과거 시험은 원래의 시스템과 산출물 범위를 유지합니다. 새 기능을 완료로 기록하려면 해당 소스에서 만든 ShizukuOS에서 실제 실행을 확인해야 합니다. 빌드·호스트 검사와 설치된 OS 실행을 구분합니다.
